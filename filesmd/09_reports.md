# Отчётность

Все отчёты строятся по `Payment.created_at` и статусам. `tips_total` и средние чаевые учитывают только `SUCCESS`; `payments_count` и знаменатель `success_rate` включают все попытки за период. Сумма чека и процент чаевых не используются.

Параметры периода `from`/`to` — включительные даты `YYYY-MM-DD`; диапазон не может быть отрицательным или длиннее 367 дней. Все endpoints требуют авторизации и проверяют область доступа.

## Отчёт мерчанта

**Endpoint:** `GET /api/v1/reports/tips?merchant_id=m_001&from=2025-11-01&to=2025-11-30`

Доступен владельцу собственного мерчанта или staff-администратору.

| Метрика | Формула |
|---|---|
| `tips_total` | Сумма `tip` успешных платежей |
| `payments_count` | Число всех платежных попыток |
| `avg_tip_amount` | `tips_total / число SUCCESS`; 0, если успехов нет |
| `success_rate` | `число SUCCESS / все попытки`; 0, если попыток нет |

```json
{
  "merchant_id": "m_001",
  "period": "2025-11-01-2025-11-30",
  "tips_total": "245.90",
  "payments_count": 4,
  "avg_tip_amount": "81.97",
  "success_rate": 0.75
}
```

## Отчёт сотрудника

**Endpoint:** `GET /api/v1/reports/tips?employee_id=e_001&from=2025-11-01&to=2025-11-30`

Сотрудник может запросить только собственный `employee_id`.

| Метрика | Формула |
|---|---|
| `tips_total` | Сумма чаевых успешных платежей сотруднику |
| `payments_count` | Все попытки платежа сотрудника |
| `avg_tip_amount` | Среднее `tip` успешных платежей |
| `top_day` | День с максимальной суммой успешных чаевых, `null` при отсутствии успехов |

```json
{
  "employee_id": "e_001",
  "period": "2025-11-01-2025-11-30",
  "tips_total": "63.70",
  "payments_count": 2,
  "avg_tip_amount": "63.70",
  "top_day": "2025-11-01"
}
```

## Отчёт по дням

**Endpoint:** `GET /api/v1/reports/tips/daily?merchant_id=m_001&from=2025-11-01&to=2025-11-30`

| Поле | Формула |
|---|---|
| `date` | Локальная дата создания успешной операции (в настройке проекта UTC) |
| `tips_total` | Сумма `tip` успешных платежей за день |
| `payments_count` | Количество успешных платежей за день |
| `avg_tip_amount` | Среднее `tip` за день |

```json
{
  "merchant_id": "m_001",
  "daily": [
    {"date": "2025-11-01", "tips_total": "200.00", "payments_count": 2, "avg_tip_amount": "100.00"}
  ]
}
```

API возвращает `avg_tip_amount`, а не `avg_tip_pct`: процент от чека отсутствует в текущей модели. Приведённые выше значения — пример формы ответа, а не утверждение о контрольных totals всего CSV. Полный контрольный импорт не записывался в локальную БД.
